## 1. Executive Summary & Discovery

### 1.1 The Market Paradox & The Strategic Wedge
The global handwriting-to-font market is polarized into two entrenched categories:
1. **Legacy Paid Utilities (e.g., Calligraphr, YourFonts):** Slow, rigid, Latin-only tools that lock personal handwriting behind monthly subscription paywalls ($8/month) or archaic per-font fees ($9.95/font).
2. **Free Ecosystem Killers (e.g., FontCrafter):** Modern, privacy-centric, feature-rich tools that have completely commoditized the English/Latin handwriting font space with zero accounts and companion apps.

**The Untapped Opportunity:**  
Every single incumbent — whether legacy paid or modern free — operates exclusively on the Latin alphabet (or basic Cyrillic/Greek). **None of them support Indic scripts.**

In Bengali (বাংলা) and Hindi (हिन्दी / Devanagari), a production-grade font requires complex glyph closures:
- Base consonants & independent vowels
- Vowel signs (*matras* / কার / मात्रा)
- Conjuncts (*yuktakshars* / যুক্তবর্ণ / संयुक्ताक्षर)
- Shirorekha / top-line continuity and kerning anchors (often 500 to 1,000+ glyph variants).

**Hatekhori's Organic Moat:**  
Hatekhori does not fight a losing battle trying to be "another English Calligraphr clone." Hatekhori dominates the high-intent, zero-competition organic territory of **Indic handwriting typefaces**, while capturing high-converting commercial switcher traffic via **"Calligraphr alternative / no-subscription handwriting font maker"** intent.

## 4. Technical SEO Baseline & Core Web Vitals Targets

### 4.1 On-Page Standards
- **Title Tag Formulation:** `Primary Keyword — Key Value Hook | Hatekhori` (Strictly 50–60 characters).
  - *Example:* `Calligraphr Alternative: Free & Indic-Ready Font Maker | Hatekhori` (67 char trimmed to: `Calligraphr Alternative: Free Indic Font Maker | Hatekhori`)
- **Meta Description Formulation:** Active verb, clear differentiator, 140–158 characters.
  - *Example:* `Turn your physical handwriting into installable OpenType fonts. Zero subscriptions, zero AI hallucinations, and 100% native support for Bengali, Hindi, & English.` (163 char trimmed to: `Turn your handwriting into installable OpenType fonts. Zero subscriptions, no accounts, and native support for Bengali, Hindi, & English. Print & scan now.`)
- **Heading Architecture:** Exactly one semantic `<h1>` matching page title intent; logical descending order `<h2>` for thematic sections, `<h3>` for feature breakdown.
- **Self-Referencing Canonicals:** Every indexable URL must declare an absolute self-referencing canonical tag `<link rel="canonical" href="https://hatekhori.com/..." />`.
- **Language & Multilingual Targeting:** Clean `hreflang` implementation supporting English, Bengali (`bn-IN`, `bn-BD`), and Hindi (`hi-IN`).

### 4.2 Core Web Vitals Baseline Targets (2026 Strict)

| Metric | Google "Good" Threshold | Hatekhori Target | Technical Implementation |
|---|---|---|---|
| **LCP (Largest Contentful Paint)** | ≤ 2.5s | **< 1.1s** | System serif / Tiro fonts preconnected; zero heavy hero raster imagery; inline critical SVG. |
| **INP (Interaction to Next Paint)** | ≤ 200ms | **< 50ms** | Zero main-thread blocking during specimen typing; lightweight DOM matrix; Web Workers for vectorization. |
| **CLS (Cumulative Layout Shift)** | ≤ 0.1 | **0.000** | Explicit dimensions on glyph canvas, font containers, and SVG preview elements; no layout thrashing. |

### 4.3 Generative Engine Optimization (GEO) & Agent Readiness
- **Entity Grounding:** Declare Hatekhori in Schema.org as a `SoftwareApplication` and `TypefaceAtelier` specializing in Indic complex script typography.
- **Direct Answer Passages:** Every guide and comparison page must feature an authoritative 60-word summary directly under the H1, explicitly engineered for AI Overview and Perplexity citations.
- **`llms.txt` Standard:** Maintain a clean `/llms.txt` and `/llms-full.txt` detailing supported Unicode blocks (U+0980–U+09FF for Bengali, U+0900–U+097F for Devanagari), vectorization accuracy, and zero-account privacy features.

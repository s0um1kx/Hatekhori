## 1. Intent-First Methodology & Clustering Strategy

### 1.1 Intent-First vs. Volume-First Philosophy
Traditional search engine optimization often defaults to targeting keywords with the highest aggregate monthly search volume. In specialized typography and software engineering domains, this volume-first approach produces massive intent dilution, attracting casual browser searchers who bounce immediately upon discovering a tool requires printing paper or specific script knowledge.

Hatekhori implements an **Intent-First Architectural Model** governed by OpenSEO principles:
1. **Transactional Intent (High Conversion)**: Searchers explicitly looking to turn their physical handwriting into a downloadable font file right now (e.g., `bengali handwriting font maker`, `bangla handwriting to ttf`, `turn handwriting into font free`). These searchers require immediate access to the A4 guideline sheet and upload studio without registration gates.
2. **Commercial Investigation Intent (Evaluation & Comparison)**: Searchers seeking alternatives to existing tools, evaluating limitations, or comparing feature sets (e.g., `calligraphr alternative`, `calligraphr free alternative`, `sites like calligraphr`, `calligraphr character limit workaround`). These users require comprehensive side-by-side matrices, transparent pricing comparisons ($0 vs $8/mo), and script capability proofs.
3. **Informational & Cultural Intent (Linguistic Craft & Education)**: Searchers seeking guidance on how handwriting typography works in Indic scripts (e.g., `নিজের হাতের লেখা ফন্ট তৈরি করুন`, `বাংলা ফন্ট তৈরি করার নিয়ম`, `अपने लिखावट का फॉन्ट कैसे बनाएं`, `devanagari shirorekha continuity`). These users require step-by-step educational documentation that seamlessly funnels into the studio.
4. **Technical & Generative Engine Optimization (GEO Intent)**: High-precision technical queries posed to AI search engines (ChatGPT Search, Perplexity, Google AI Overviews) regarding font specifications, OpenType tables, Bézier contour tracing, and privacy (e.g., `bezier curve handwriting font generator`, `potrace python font maker`, `privacy handwriting font exif`).

### 1.2 Dual-Script & Bilingual Search Mechanics
The South Asian digital sphere exhibits a unique linguistic bifurcation. Millions of native speakers in Bangladesh, West Bengal, and northern India search using Latin alphabet transliterations (e.g., `bangla handwriting font maker`, `hindi font generator`), while millions of others search directly in native Indic Unicode scripts (e.g., `হাতের লেখা ফন্ট বানানোর সফটওয়্যার`, `अपने लिखावट का फॉन्ट कैसे बनाएं`).

To capture both audiences without creating duplicate or cannibalized pages, Hatekhori implements a **Bilingual Single-Page Architecture**:
- Primary URLs are semantic English slugs (`/bengali-font-maker`, `/hindi-font-generator`).
- Page markup features native script metadata: `<html lang="bn">` with Bengali titles, descriptions, and OpenGraph text; `<html lang="hi">` with Hindi titles, descriptions, and OpenGraph text.
- On-page body copy seamlessly interweaves technical English typography terms (OpenType, TTF, WOFF2, Bézier curves) with native linguistic nomenclature (স্বরবর্ণ, ব্যঞ্জনবর্ণ, কারচিহ্ন, যুক্তবর্ণ, शिरोरेखा, संयुक्ताक्षर, मात्राएं).
- Search engines index both script variants to a single authoritative canonical destination.

### 1.3 Cannibalization Prevention Architecture
Keyword cannibalization occurs when multiple URLs within a single domain target identical search intent, confusing search crawlers, diluting link equity, and causing rankings to fluctuate.

Hatekhori enforces strict topic-to-URL boundaries:
- **Bengali Linguistic Queries** $\rightarrow$ Exclusively mapped to `/bengali-font-maker`.
- **Hindi & Devanagari Linguistic Queries** $\rightarrow$ Exclusively mapped to `/hindi-font-generator`.
- **Competitor Alternative & Pricing Queries** $\rightarrow$ Exclusively mapped to `/compare/calligraphr-alternative`.
- **Generic English Atelier & Core Studio Queries** $\rightarrow$ Exclusively mapped to root `/`.
- **Printable Template Downloads** $\rightarrow$ Mapped to designated guideline sheet PNG endpoints (`/guideline-sheet-*.png`) linked directly from their corresponding topic pages.

## 5. Cannibalization Prevention & Domain Boundary Rules

### Rule 1: Bengali Script Linguistic Boundary
- Any query containing `bengali`, `bangla`, `বাংলা`, `স্বরবর্ণ`, `ব্যঞ্জনবর্ণ`, `কারচিহ্ন`, or `যুক্তবর্ণ` belongs exclusively to `https://hatekhori.onrender.com/bengali-font-maker`.
- Internal links from other pages targeting Bengali typography must anchor with `href="/bengali-font-maker"`.
- Under no circumstances should `/` or `/compare/calligraphr-alternative` attempt to rank as primary landing pages for standalone Bengali font generation terms.

### Rule 2: Hindi & Devanagari Linguistic Boundary

- Internal links from other pages targeting Hindi typography must anchor with `href="/hindi-font-generator"`.

### Rule 3: Competitor Switcher Boundary
- Any query containing `alternative`, `vs`, `Calligraphr`, `Lipighor`, `Fontself`, `FontCrafter`, `YourFonts`, `iFontMaker`, `pricing`, or `review` belongs exclusively to `https://hatekhori.onrender.com/compare/calligraphr-alternative`.

### Rule 4: Generic English Atelier Core Boundary
